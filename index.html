Built to be taken apart

Every card is rendered inside a Shadow DOM, so no two demos can ever fight over a class name. Hit Code to read the exact HTML, CSS and JS that produces it, or Customise to retune it — the snippet you copy out already carries your settings.

🎛️ Tune every effect

Open the Customise panel on any card: speed, colours, size, glow, direction, easing plus that demo's own parameters. Settings persist per effect, can be pushed to all 900 at once, and are baked into the snippet you copy.

⚡ Static & fast

No framework, no bundler, no build step. It is HTML, CSS and a few kilobytes of JavaScript, served straight from GitHub Pages.

🧪 Isolated demos

Shadow roots + lazy mounting mean 900 animated demos on one page without your fan taking off.

♿ Respectful motion

Honours prefers-reduced-motion, and there is a global pause button in the header for everyone else.
