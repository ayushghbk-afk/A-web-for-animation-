Ae

A browser cannot safely forge Adobe's binary project format. Motion Lab does the reliable thing instead: it downloads a small .jsx builder, then After Effects creates and saves the real project itself.

  1. 01
    Choose any effect

    Tune speed, scale, colours and parameters first, then press Generate After Effects builder on its card.

  2. 02
    Run one script

    In After Effects choose File › Scripts › Run Script File and select the downloaded builder.

  3. 03
    Edit native layers

    The script creates named shape/text layers, a Controls null, expressions, usage notes and a transparent 60 fps comp.

Native recreation, not a wrapped web page. DOM, CSS and canvas do not exist in After Effects. The bridge maps each effect's mechanism, timing, palette and tuning to AE primitives; complex browser-only rendering can differ.

More from @ayushghbk-afk How this site works

Built to be taken apart

Every card is rendered inside a Shadow DOM, so no two demos can ever fight over a class name. Read the exact web source, retune it, or send its mechanism to a native After Effects rig — every export carries your current settings.

🎛️

Tune every effect

Open the Customise panel on any card: speed, colours, size, glow, direction, easing plus that demo's own parameters. Settings persist per effect, can be pushed to all 1,800 at once, and are baked into the snippet you copy.

⚡

Static & fast

No framework, no bundler, no build step. It is HTML, CSS and a few kilobytes of JavaScript, served straight from GitHub Pages.

🧪

Isolated demos

Shadow roots, a shared rAF pump, off-screen CSS pause and destroying far-away demos mean 1,800 cards without keeping hundreds of live instances.

♿

Respectful motion

Honours prefers-reduced-motion, and there is a global pause button in the header for everyone else.

Run this file from File › Scripts › Run Script File. It creates organized layers, expressions, a Controls null, README guide layer and transparent composition—then asks where to save the real Adobe files.

Start in a blank project for a standalone file. If another project is open, the builder asks before adding anything. AEP/AEPX are always written by After Effects itself—not imitated in the browser.
